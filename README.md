# NaRota — downloads

Programa de vendas para distribuidoras: pedidos, clientes, estoque e nota fiscal.

## Baixar

- **PC (Windows):** [NaRota-windows.zip](https://github.com/marcosgcardoso2311/narota-downloads/releases/latest/download/NaRota-windows.zip)
  Descompacte e dê dois cliques em **Instalar.cmd**. Se o Windows avisar "O Windows protegeu o computador", clique em **Mais informações › Executar assim mesmo**.
- **Celular (Android):** [NaRota-android.apk](https://github.com/marcosgcardoso2311/narota-downloads/releases/latest/download/NaRota-android.apk)
  Toque no arquivo baixado e permita instalar apps desta fonte. Ou, no PC: **Ajustes › Celulares**, leia o QR code com o celular.

Todas as versões: [Releases](https://github.com/marcosgcardoso2311/narota-downloads/releases)
